v0.1.1 的全部范围已实施完成：两项缺陷修复（行内指法图布局、来源标注移除）、字符级制谱锚定、视觉层级与复古排印、纸纹质感、过渡动效、和弦概览互补呈现，以及实施过程中经 Simon 确认追加的工具栏无框化。`package.json` 版本已改为 `0.1.1`。

## 2. 实际完成的交付

### 2.1 行内指法图布局修复

使用 The Cure 真实谱包展开全谱指法图时，歌词行出现指法图压段落标题、压上一行歌词、相邻指法图互相重叠的问题。根因是歌词行布局按单行和弦名设计：锚点零占位、按钮绝对定位、行上方仅预留 1.8em。

最终交付的形态经过两次迭代：先以「行 `padding-top` 预留空间 + 全部锚点撑宽 58px」修复重叠，因歌词被撑出空隙被否，改为「锚点零宽、歌词连续、拥挤锚点按需撑宽」；随后在移动端视口发现换行视觉行没有预留空间、指法图侵入上一行文字，最终定为**锚点槽位自身高度 7.2em** 的方案：每个含锚点的视觉行独立获得图示空间，与视口宽度和换行无关。拥挤锚点（中心距小于 64px）由 `LyricScoreLine` 的运行时测量撑宽前一个槽位。

### 2.2 指法图来源标注移除

应 Simon 要求移除指法图下方的「来源已核验 / 内置指法库」可见小字。指法图的无障碍标签保留核验来源信息；只渲染 `verified` 指法的数据层要求不变。

### 2.3 视觉层级与复古排印

歌词改为衬线字族，段落标签启用小型大写并加宽字距，歌头元信息的值改为衬线旧式数字、标签降为 `--quiet`；和弦名与指法图标注保持等宽体，形成记谱与文学文本的对比。顶栏取消软阴影只留 1px 分隔线，「编辑」等全部按钮改为细边框 quiet 风格、激活态用 accent 边框与文字。工具栏按 Simon 确认的无框工具行方案去除胶囊容器，组间以 1px 竖细线分隔，移动端取消分隔线。谱纸叠加极淡的 SVG 灰度颗粒纹理（打印时移除），歌头改为书版双线。全部颜色 token 定义值与 v0.1.0 相同。

### 2.4 过渡动效

新增 `--ease-editorial` 缓动 token。切换全谱指法显示时锚点槽位高度平滑过渡（280ms，谱面呼吸）；指法图入场淡入上浮（220ms，`diagram-in`）；转调后和弦符号经 React `key` 重挂载淡入（160ms，`chord-symbol-in`）；正文和弦悬停出现极淡 accent 洗色，概览指法图悬停轻微上浮并加深阴影。全部动效仅使用 `transform`/`translate`/`opacity`，由既有 `prefers-reduced-motion` 媒体查询统一关闭。

### 2.5 和弦概览互补呈现

`name` 模式下概览显示指法图网格（名称模式下唯一的图示入口），`nameAndDiagram` 模式下概览收缩为单行和弦名列表，不再与正文重复显示同一批图。全局开关的入口与文案不变。后续 e2e 断言统一加载字符级 The Cure 基准包：默认 `name` 模式验证概览图示，切换后验证「概览无图、正文有图」。

### 2.6 字符级制谱锚定与 The Cure 基准包

制谱 Skill 现以“和弦根音首字母 → 歌词具体字素边界”建立锚点：PDF 没有截图时先渲染为图片，图片与 PDF 逐和弦读取根音首字母的视觉位置；保留布局的文字在清理空白前完成同列映射。最终仍只保存 `anchor.graphemeOffset`，不持久化像素坐标。位置无法直接判定时必须标记低置信，不能将和弦粗略吸附到单词开头。

本次已用用户提供的三页 The Cure PDF 生成 `output/the-cure-test-run/the-cure-olivia-rodrigo.character-anchor-test.chordsheet`。该谱包包含 11 个段落、49 行、94 个和弦事件，原 PDF 未嵌入；一行歌词因源 PDF 中视觉相同的非 ASCII `e` 规范化而标记为低置信内容冲突。JSON 与归档均通过项目校验器。此包自此作为所有测试的唯一默认输入，历史演示谱和旧参考包不再作为测试基准。

## 4. 与方案的偏差

1. 行内布局机制由方案中的「行 `padding-top: 6.5em`」改为「锚点槽位高度 7.2em」。原因：`padding-top` 只覆盖段落顶部，移动端换行后的视觉行没有预留空间，指法图侵入上一行文字。PRD 第 7 节与实施方案第 3 节已按最终方案更新。
2. 锚点槽位宽度修正不做动画（方案原为宽度平滑过渡）。原因：算法先清空宽度再测量，宽度回退动画使 `getBoundingClientRect` 读到中间几何，与 `ResizeObserver` 重跑竞态导致撑宽丢失；改为即时生效后测量始终读到稳定几何。谱面呼吸保留槽位高度过渡。
3. 工具栏无框化（去除胶囊容器）是实施过程中 Simon 提出并确认的新增范围，已补入 PRD 第 4.1 节与实施方案第 5.1 节。

## 5. 已知问题与边界

1. 桌面与移动端视口已通过程序化边界框检测；中间断点（如 820–1000px）未逐一截图检查，布局机制与宽度无关，预期一致。
2. `npm run build` 的 chunk 体积警告（>500 kB）为 v0.1.0 既有现象，与本版本无关。
3. 换行频繁的小屏上，指法图模式下谱面纵向明显变长（每个含锚点视觉行约 7.2em），这是保证不重叠的取舍。

## 6. 与上一版本文档的关系

v0.1.0 的 PRD、实施方案与 Release 记录继续作为产品基线与架构权威有效。本版本额外细化三处：概览与正文同步显示的要求改为互补呈现；「不使用无用途动画」的边界允许已定义的功能性过渡；制谱锚定必须从词级推断收紧为根音到具体字素的映射。v0.1.0 Release 第 4 节中的 The Cure 完整制谱验收已由本次基准包完成候选转换与校验，但仍保留 1 个低置信内容冲突，不能声称全部人工确认；编辑器覆盖范围、来源移除选择、真实 PDF 分页验收与多模态识别服务仍不在本版本范围内。
