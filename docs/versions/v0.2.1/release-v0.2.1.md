## 1. 本次变更

有谱么新版复制不再携带完整 JSON 节点，而通过随机标识关联其域名下的浏览器缓存，导致旧版“复制到有谱么”失效。本次按用户确认的方案，以“导入到有谱么”及可拖入书签栏的歌曲导入书签替换旧入口，删除旧剪贴板载荷生成和文本框降级实现。

书签保存当前谱面及转调快照，在有谱么草稿页写入新版缓存并调用编辑器粘贴处理逻辑，目标行为为点击书签后直接插入谱面。已有草稿确认后追加末尾；错误页面、无法识别编辑器或缓存写入失败时停止。操作步骤、协议、未传递资料及技术边界统一见 [有谱么新版导入适配](../../technical/yopu-import-bookmark.md)。

本补丁需求由 [v0.2.1 简要 PRD](prd-v0.2.1.md) 定义，沿用 v0.2.0 基线，仅替代旧版有谱么剪贴板流程。根 README 面向外部读者介绍产品、主要功能与使用方式；技术细节留在适配说明。已发布历史文档保持不变。
