## 1. 背景与目标

有谱么新版复制内容只携带关联浏览器缓存的标识，旧版“复制到有谱么”输出的完整 JSON 剪贴板内容已无法沿用。v0.2.1 修复已有的外部编辑流程，让用户把 ChordSheet 当前谱面带入有谱么继续编辑，并保留段落、歌词、和弦及字符落点。

本版本是适配补丁，不新增制谱模式或修改 `.chordsheet` 数据格式。本文替代 v0.2.0 PRD 第 8 节的旧版剪贴板交互及相关验收项；其余产品基线继续有效。

## 2. 用户流程与行为

1. 用户打开谱包，点击“导入到有谱么”，看到可拖动的歌曲导入书签、操作说明及不能传递的资料。
2. 用户将按钮拖到 Chrome 书签栏，在有谱么草稿页点击保存的书签，直接插入谱面，无需手工复制粘贴。
3. 空白草稿直接导入；已有内容时先提示确认，确认后追加末尾，取消不改变草稿。
4. 书签保存生成时的谱面与当前转调。修改或转调后，用户重新生成并替换书签。
5. 在错误页面、无法识别编辑器或写入缓存失败时停止并提示，不能把失败表示为导入成功。

导入后用户核对谱面并补充歌曲资料。此动作不表示已投稿或发布；有谱么编辑器自身可能自动保存草稿。

## 3. 范围与限制

本次移除旧版复制入口、JSON 剪贴板载荷和复制失败文本框，保留原有谱包导入导出、本地保存、阅读、编辑和指法选择能力。

可传递内容包括段落顺序、逻辑换行、歌词与空格、当前显示的和弦名称、字符级落点及纯和弦行事件顺序。标题、歌手、来源记录、Capo、节拍与节奏型、段落重复次数、自选指法和纯和弦时值不能自动传递；注释行按普通文字处理，生成书签时需说明这些影响。

本版本不提供任意有谱么曲谱的反向导入，不自动登录、上传或投稿，不承诺支持其他网站或浏览器。协议与技术实现统一见 [新版导入适配说明](../../technical/yopu-import-bookmark.md)。

## 4. 验收条件

1. 旧版复制入口已移除，新入口能生成当前谱面的书签并清楚说明使用步骤和限制。
2. 自动化验证覆盖字素锚点、转调、完整基准谱节点、错误页面、取消追加、存储失败及既有功能回归。
3. 在真实有谱么编辑器使用 The Cure 完整字符锚定基准谱执行书签导入，段落、逻辑换行、歌词与空格、和弦名称及精确落点均无偏差；重新复制后节点语义一致。
4. 记录真实验收日期、浏览器环境及偏差。只有真实验收通过后，交付记录才可标记为 `released`；本地测试通过不能代替兼容验收。

基准谱路径和当前验证结果以 [交付记录](release-v0.2.1.md) 为准。
