## 2. 实际交付

### 2.1 本曲多指法选择

同一和弦现在可打开选择器，桌面端显示靠近触发位置的浮层，窄屏显示底部抽屉；点击、右键、键盘和触屏都进入同一选择流程。选择会应用到本曲全部基础符号精确相同的和弦，保存为歌曲内的完整 Voicing 副本；恢复默认时只移除本功能创建且不再引用的副本。C 与 C/G 等不同符号不会互相影响，转调后也不会继续使用原显示和弦的指法。

UI 仅新增选择器与复制到有谱么入口，复用原有颜色、排版、按钮和响应式设计，未重做既有谱面或编辑器界面。

### 2.2 数据支持的四个候选

主库 @tombatossals/chords-db v0.6.0 中有 828 个和弦键、3,283 个指法位置；774 个键原本正好有 4 个位置，16 个有 5–7 个。position 只表示变体，并不提供使用频次，因此本版本不把结果称为全网统计意义上的最常用。

应用保留主库不变，并从固定的 ChordPro 6.101 标准吉他配置中生成 src/data/chordpro-common-voicing-order.json：其中 240 个和弦键的指法与主库位置完全同形。默认候选先排除起始把位高于第 5 把的形状，再按低把位、开放弦、无横按、较小跨度、较少闷弦排序；ChordPro 同形记录只在前述条件并列时使用。低把位不足 4 个时不以高把位形状补足。已保存的用户选择仍优先保留，即使它不在默认四个内。

### 2.3 有谱么兼容剪贴板导出

已新增复制到有谱么。导出生成用户样本中的可读文本、固定哨兵和 HEADLINE、TEXT、CHORD_ANCHOR、LINE_BREAK 节点流；歌词锚点按 Unicode 字素转换，空白和行末锚点不被错误消费，和弦名称按当前转调导出。标题、歌手、Capo、节奏、来源、段落重复和自选指法不能由样本协议传递，复制前会明确提示；浏览器拒绝剪贴板权限时，页面提供可全选复制的完整文本框。

### 2.4 指法库维护、Skill 与回归谱包

新增可重复运行的指法库审计与 ChordPro 比较/排序索引脚本，并在 THIRD_PARTY_NOTICES.md 记录 ChordPro v6.101、固定 commit、Artistic License 2.0 和仅位置索引的使用范围。Notion 谱包的字符级锚定修正已固化：A 对齐 r（53），Faug 对齐 s（55），5 行前导空白与 1 行尾随空白保留。可下载的 Skill 包已更新为 public/downloads/chordsheet-builder-skill-v0.2.0.zip。

## 4. 验收结论与外部验证边界

项目负责人于 2026-08-18 确认按当前交付定版，Release 由 release-candidate 定稿为 released。

真实有谱么草稿的自动化接管仍不稳定，未将合成粘贴事件当作真实兼容证明；这一已知外部验证限制保留在本记录。后续如发现真实粘贴偏差，应回到 src/domain/yopuClipboard.ts 修正，并以补丁版本补充本记录。

## 5. 已知边界

1. 常用候选表示第 5 把以内的常见形状和本地可演奏性排序，不表示互联网使用频次或唯一正确指法；ChordPro 只用于低把位候选的并列排序；
2. 指法选择的作用域是本曲全部基础符号精确相同的和弦，不支持仅改一次或自动按相邻和弦推荐；
3. 有谱么导出不传递其样本协议没有表示的位置资料、节奏、Capo、重复和自选指法；
4. 本次未创建 Git 提交、Tag、PR 或部署，也未推送远端。
5. 真实有谱么编辑器的自动化接管未作为兼容证明；若后续发现粘贴偏差，以补丁版本修正。
